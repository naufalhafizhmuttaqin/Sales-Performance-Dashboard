# 📊 Sales Performance Analytics Dashboard

An end-to-end Data Analytics project that analyzes retail sales performance using **Python**, **SQL**, and **Power BI**. This project covers the complete analytics workflow, including data cleaning, exploratory data analysis (EDA), SQL-based business analysis, and interactive dashboard development to generate actionable business insights.

---

## 📌 Project Overview

This project aims to analyze retail sales performance from a Superstore dataset to identify sales trends, customer behavior, product performance, and regional profitability.

The workflow follows a real-world data analytics pipeline:

- Data Cleaning & Feature Engineering using Python
- Exploratory Data Analysis (EDA)
- Business Analysis using SQL
- Interactive Dashboard using Power BI
- Business Insights & Recommendations

---

## 🎯 Business Objectives

This analysis answers several business questions, including:

- Which product categories generate the highest sales?
- Which regions contribute the highest profit?
- Who are the top-performing customers?
- Which products generate losses?
- How does discount affect profitability?
- What are the monthly sales trends?
- Which customer segment contributes the most revenue?

## 🧹 Data Cleaning

The raw dataset was intentionally modified to simulate real-world business data and improve the data cleaning process.

Cleaning tasks included:

- Handling missing values
- Removing duplicate records
- Standardizing text formatting
- Correcting inconsistent capitalization
- Fixing typographical errors
- Parsing mixed date formats
- Removing invalid sales and quantity values
- Handling outliers
- Creating analytical features

Additional engineered features:

- Order Year
- Order Quarter
- Order Month
- Order Month Name
- Order Weekday
- Shipping Days
- Profit Margin (%)
- Sales per Unit
- Profit per Unit

## 💡 Key Business Insights

- Technology is the highest revenue-generating category.
- Higher discounts generally reduce profitability.
- A small number of customers contribute a significant portion of total sales.
- Some products generate high sales but negative profit.
- Sales performance varies significantly across regions.
- Monthly sales show seasonal fluctuations that can support future planning.

---

## 🚀 Business Recommendations

- Review high-discount products with consistently low profit margins.
- Focus marketing efforts on high-value customer segments.
- Increase inventory for top-performing products.
- Improve profitability in underperforming regions.
- Monitor discount strategies to maximize profit without sacrificing sales.
